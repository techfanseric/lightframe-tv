# IPTV 离线准备与安装

轻幕新增 `IPTV` 入口，对应 [我的电视 tv2.2.7](https://github.com/yaoxieyoulei/mytv-android/releases/tag/tv2.2.7)，包名 `top.yogiczy.mytv.tv`。官方 APK 的最低系统为 API 21，适用于本项目已记录的 Android 9 电视；已在该电视安装并完成节目源导入，用户确认使用效果；这不代表所有频道的播放和解码均已逐项验证。该上游项目目前已归档，安装包保持官方签名，不修改或重签。

菜单、开机指定应用、跟随上次、最近使用排序及当前应用排除都支持第四个应用。IPTV 不走 YouTube / Netflix 的代理等待流程，状态栏保留现有智能显示逻辑。

## 已准备内容

运行 `python3 scripts/prepare-iptv.py` 下载官方 APK，以及 [iptv-org](https://github.com/iptv-org/iptv) 的全球、大陆、香港、台湾和中文公开源。所有 APK、节目源副本、哈希和本地清单保存在忽略目录 `.local/iptv/`，不提交到 Git。

2026-10-19 准备时，全球原始列表包含 11,361 条播放条目。播放器的 M3U 解析器要求 EXTINF 后紧接 URL，且不处理频道专用请求头，因此兼容列表排除带 EXTVLCOPT / KODIPROP 的条目及不支持的协议。默认合并列表按大陆、香港、台湾、中文、全球顺序去重，得到 10,630 个播放地址；原始文件同时保留。此数字表示节目单中的地址数量，不表示已确认可播放的频道数。

兼容节目单统一使用中文主分类：例如 `Movies;Series` 归入“电影”，`Animation;Kids` 归入“少儿”，`Undefined` 归入“其他／待分类”。特定类别优先于综合、娱乐等宽泛标签，未知标签归入待分类。2026-10-20 对同一批源归类后，从 178 个原始分组合并为 30 个中文分组，播放地址与频道名称保持不变。原始下载快照保留上游分类。

已有本地源时，可只重新生成分类，不下载新的节目源：

```sh
python3 scripts/prepare-iptv.py --offline
```

再运行导入脚本更新电视文件；重新打开 IPTV 后载入。只更改分类无需重装轻幕或播放器。

频道元数据会从 [iptv-org 频道数据库](https://iptv-org.github.io/api/channels.json) 保存到本地；国内频道优先使用经核对的中文名或原生中文别名，海外频道仅对已有通行中文名的品牌显示“原名（中文名）”。不把日文假名、韩文汉字别名自动当作中文译名。没有可靠译名时保留原名，频道标识和线路地址不变；改名时将原显示名保存到 `tvg-name`，保留 MyTV 原先的 EPG 查询键。

分类补全使用明确的频道身份规则及频道名中直接表达的主题，不以国家、域名或泛称“TV”推断类别。2026-10-20 对同一批节目单的补充核对，将 366 条未分类内容归入已知类别，剩余 1,045 条保留待核实；同时更正安多卫视、CCTV-8 等已知分类错误。共更新 351 条频道显示名，仍保持 30 个分类和 10,630 条播放地址。少数以英文品牌运营、尚未核实中文名的国内频道保留原名。

原始元数据、处理依据及名称迁移表分别保存在 `.local/iptv/channel-metadata.json`、`channel-audit.json` 和 `name-migrations.json`。MyTV 按显示名保存收藏；重新导入时，工具会将旧名收藏迁移到新名，保留其他收藏及偏好。只后台替换源文件不会修改播放器收藏设置，需要在 IPTV 配置服务运行时执行导入才能迁移。

离线回归检查：`python3 scripts/test_iptv.py`。

另提供“全部公开频道（按地区）”源，与按内容分类的源分开，避免同一节目单内重复列出频道。导入后可在播放器的直播源设置中切换。地区源保持相同的 10,630 条播放地址、显示名及 EPG 标识，按以下顺序分组：大陆、香港、澳门、台湾、日本、韩国、东南亚、南亚、中亚及高加索、中东及北非、欧洲、北美洲、拉丁美洲及加勒比、撒哈拉以南非洲、大洋洲、其他亚洲、地区待核实。

地区依据频道数据库的所属地，而非播出语言或可接收范围。俄罗斯归欧洲、土耳其归中东及北非，高加索国家与中亚合组；美国之音中文电视按美国归北美。所属地资料缺失时不从语言或播放服务器地址猜测，目前有 3 条保留为地区待核实。首次导入默认选中按内容分类的源；只追加地区源而保持当前选择时运行：

```sh
python3 scripts/configure-iptv.py "$TV_ADB_SERIAL" --keep-current
```

各组内部使用“中文常看台优先、海外主流台随后”的编辑推荐顺序，不表示真实收视率或实时热度。明确列出的央视、主要卫视和港台常看频道优先；随后是列出的海外主流频道与品牌，再排上游中文节目单中的其他频道及其余国内品牌。剩余频道按原生台名自然排序，同一频道 ID 的不同线路连续排列，不按播放服务器或清晰度猜测受欢迎程度。规则位于 `scripts/iptv_order.py`，本地清单记录排序版本。排序仅改变条目位置，不删减节目或更改播放地址、显示名及 EPG 标识。

源列表来自公开频道集合，不包含运营商账号、付费频道凭据或私人订阅。地域限制、网络条件和源失效都会影响播放。没有对全部地址进行播放验收。EPG 沿用播放器现有配置，本次未验证节目预告匹配。

## 电视开机后

先在项目根目录准备文件（安装已有 Release APK 时不需要重新构建轻幕）：

```sh
python3 scripts/prepare-iptv.py
```

将 Release 的 `LightframeHome.apk` 和 `LightframeOverlay.apk` 放入 `dist/`；或按 README 的构建说明生成它们。然后执行（先保证 ADB 已连接并获授权）：

```sh
./scripts/install-iptv.sh "$TV_ADB_SERIAL"
```

默认只安装三个 APK，不启动应用、不按遥控器键、不改默认桌面、不重启。之后用遥控器打开 IPTV，再执行：

```sh
python3 scripts/configure-iptv.py "$TV_ADB_SERIAL"
```

如果准备好让脚本打开 IPTV 并导入，可明确使用：

```sh
./scripts/install-iptv.sh "$TV_ADB_SERIAL" --launch-and-configure
```

导入脚本通过 ADB 端口转发连接播放器自身的配置接口；将全部兼容节目单存入播放器专属外部文件目录，合并源列表并默认选中“全部公开频道（中文优先）”，读取配置确认后移除转发。现有其他源、收藏、节目预告和显示偏好保留。重复导入同路径源不会新增重复项。首次使用若播放器要求确认使用协议，需在电视上自行完成，再重跑导入。

导入成功后，关闭并重新打开 IPTV，使界面载入新的本地节目单。首次导入已在目标电视确认原始分类解析为 178 个分组、10,630 条播放地址；中文归类后的列表含 30 个分组，需重新载入。

本地副本可以避免首次载入依赖节目单网站，但播放仍需联网。需要更新源时，重新运行准备脚本和导入脚本。只更新兼容列表；不会清除应用数据。
