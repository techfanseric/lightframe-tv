# 轻幕 · Lightframe TV v0.1.0

首次项目发布：无独立首页，开机直达指定视频 App，观看时按首页键直接切换。

- 默认跟随上次应用，也可指定 YouTube、哔哩哔哩或 Netflix。
- 自动检测并启动已配置的 FlClash，等待目标网络就绪后打开海外视频 App。
- 顶部网络状态条显示节点、延迟、速率与曲线，默认在 B 站隐藏。
- 两行直接操作菜单，最近使用排序、隐藏当前应用、遥控器循环导航。
- YouTube 专用广告声音开关默认关闭，通过外部助手生效。
- 信号源/HDMI 原生桥接；中文/英文应用名称与文档。

## 安装

同时安装 LightframeHome.apk 和 LightframeOverlay.apk，再授予悬浮窗与使用情况访问，并将轻幕设为默认 HOME。详见 README。两个 APK 使用同一签名；源仓库不包含私钥、订阅或接口 token。

本次重命名保留原包名以支持现有设备更新：HOME 8.1/code9，Overlay 8.12/code21。

已在 Android9/ARM32 小米电视固件开发，其他设备的原生设置、HDMI 与遥控器需实机确认。代理配置、视频应用与登录需另行准备；局部渐隐衬底不是真实跨应用动态模糊。
