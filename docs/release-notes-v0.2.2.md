# v0.2.2 · 流光启动过渡

轻幕在准备连接和打开应用时显示简洁的流光等待页：应用标识、固定状态文字和遥控提示集中在屏幕中上部，底部留空。默认开启流光，可改为静态或关闭；网络检查不因外观开关而跳过。应用接到前台后及时淡出并返还输入，首页或返回可取消。

同时修复开机恢复与首次 HOME 的顺序、等待中息屏、FlClash 短暂前台和重复 UsageStats 事件导致的误取消。可选守护 2.11 使用同款等待页，保留精确 Google 提示处理和原有账号数据。README 新增这台电视的真实过渡预览截图，以及可处理厂商 PNG 前缀的只读截图脚本。

版本：Home 8.6 (14)、Overlay 8.34-dock (43)、可选 PlaybackGuardian 2.11 (13)。并行包名与签名保持一致。从 v0.2.1 运行新版 setup 的 install 命令即可覆盖升级轻幕；现有第三方包仍默认跳过。已有守护 2.10 如需新等待页，应单独使用同签名的 `adb -s TV_IP:5555 install -r PlaybackGuardian-2.11.apk`，签名冲突时停止，不卸载、不清数据。

验证：用户完成目标电视验收；默认首页、开机启动开关、后台服务/权限、Clash VPN 与无障碍守护已核对；Netflix 网络预检后进入前台、YouTube 验证连接后交接且无等待窗口残留。原账号数据和家居配置保留。Android 14 模拟器覆盖取消、关闭动画、息屏恢复、前台交接及实际重启后进入等待并由 HOME 退出；55 项纯启动策略检查、设置迁移测试及 15 项安装器测试通过。**本轮没有再次执行实机冷重启，也不把进入前台当作视频首帧检测。** 新设备仍需验证实际播放及冷启动。

附件继续提供 setup/companions ZIP、TizenTube ARM32/64、FlClash ARM32/64、MyTV、可选守护、第三方来源/源码/许可证和 SHA256 校验。新增 BUILD-INFO.json 记录自有 APK 与源码提交。未包含订阅、登录数据、家庭配置或 Google 服务安装包。
