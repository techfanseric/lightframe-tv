# 兼容性与播放守护

| 项目 | 当前范围 |
| --- | --- |
| 平台 | Android 9/API28+；Tizen/webOS不支持 |
| 实机 | 已在一台Android9 ARM32小米电视验证；不是全品牌认证 |
| 核心APK | Java/Dex，无CPU特定原生库 |
| 配套应用 | TizenTube/FlClash分ARM32与ARM64；按系统ABI选择 |
| 首页/覆盖 | 固件必须允许HOME替换、悬浮窗和使用情况访问 |
| 系统设置 | 小米原生页优先，其余退回标准Android设置 |
| 信号源/HDMI | 小米专用集成，其他固件不保证 |
| 网络 | FlClash + 已授权VPN + 本地9090认证控制器；暂无直连模式 |
| Netflix | 还依赖客户端、设备认证、DRM、Google服务及线路 |

## Google服务不会自动安装或停用

某台已验证电视上，特定Google服务版本发生系统权限崩溃，停用后Netflix能播放，但出现中文启用服务提示。这是该设备的诊断结果，不是其他电视的默认修复。不要为安装轻幕而关闭GMS、清除Netflix数据或刷入不匹配的Google服务。

普通启动器GoogleServicesHealth仍检查GMS/GSF；没有Google服务的电视可能被阻止打开Netflix。可选守护仅覆盖已经确认的、存在但停用GMS的特定情形，不能补齐DRM认证，也不能处理所有语言和固件。

## 可选播放守护2.11

通过 `--companions guardian` 安装后，用户自行从系统无障碍设置启用“轻幕播放守护”。默认向导不启用、不更改其他无障碍服务。它读取限定应用的窗口事件，匹配精确Netflix提示与轻幕阻挡卡，做有界网络预检，随后尝试关闭已知提示；会绑定触发请求的同一套轻幕，前台切到另一套或用户改变意图时取消。

它会尝试通过FlClash已提供的启动入口恢复已授权VPN；不能代替订阅或VPN授权。上游FlClash版本改变入口后需重新验证。关闭守护可在无障碍设置操作，不影响其他应用账号。

Release源代码和APK包含兼容功能，但不承诺弹窗永远不出现、网络永远稳定或开机必定自动播放指定影片。实测应包含真实内容试播、菜单返回及一次冷启动。

2.11 的等待页采用同款流光与固定文字层级，网络失败停止动画并给出重试/取消。读取窗口的范围、精确 Google 提示匹配和请求取消规则保持原有边界。启动器的过渡外观开关不跨包同步给守护；两者都遵循系统动画开关。
