# Official brand assets

- **Netflix N symbol**: RGB transparent PNG distributed in the official [Netflix Company Assets](https://about.netflix.com/en/company-assets) [Symbol ZIP](https://assets.ctfassets.net/4cd45et68cgf/5vCbQ45TfVUvWgm8eiDOtn/ef1c2431dc81f79ae93fcce649ae796f/Netflix_Symbol.zip), retrieved 2026-10-30. File `02_Netflix_Symbol/01_Netflix_Symbol_RGB/Netflix_Symbol_RGB.png`. The original transparent file is retained without raster alteration; the drawable uses its ink rectangle for native layout. Logo colors are unchanged.
- **Bilibili small TV**: exact path geometry from the `bili-bilibili-tv` symbol served by [Bilibili's official header bundle](https://s1.hdslb.com/bfs/seed/jinkela/header-v2/header.js), linked from the [official app page](https://app.bilibili.com). Retrieved 2026-10-30. Original SVG saved beside this file; geometry converted to an Android vector drawable and displayed white on the Bilibili pink tile.
- **YouTube**: simple red playback mark in the existing local vector, displayed on a light tile. The target package remains TizenTube; accessibility description reads `YouTube · TizenTube`.

Third-party names and marks identify the installed applications and remain owned by their respective owners. Settings and smart-home images were generated locally with the built-in image generation tool; see `generated-entry-prompts.md`.
