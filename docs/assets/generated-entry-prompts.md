# Generated entry marks

Created with the built-in image_gen tool, transparent background. These are the flat-direction revisions used in the current preview; earlier dimensional concepts were rejected by the user and are not used. Android applies a solid tint to each silhouette for a flat visual finish and samples bitmap decoding to keep memory usage small.

Historical generated assets: `apps/overlay/res/drawable-nodpi/settings_entry_generated.png` and `apps/overlay/res/drawable-nodpi/home_entry_generated.png`. Both retain transparency. The settings mark remains in use; smart home now uses the hand-authored smart_home_symbol.xml house-and-nodes vector.
