# 启动过渡与真实截图

![目标电视的启动过渡预览实机截图](images/startup-loading-tv.png)

上图为电视上实际运行的设置预览截图，非模拟器、非合成图。

启动过渡采用深色底、应用标识和沿圆角屏幕轮廓缓慢移动的银色细线。状态固定在应用名下方，处于屏幕中上部，底部为空；应用名 22sp，状态 11sp，操作提示 10sp 且隔开 16dp，三个区域宽高固定；不显示百分比、节点名称或技术日志。提示为“返回取消 · 首页选择应用”。

设置 → **启动过渡**：流光（默认）、静态、关闭。静态保留相同排版；系统关闭动画时流光也停止。关闭只改变外观，不跳过网络检查。不依赖在线背景或大幅背景图片。

## 何时显示与退场

- 仅由轻幕主动打开应用或开机自动启动触发，不用于后台网络修复。
- YouTube / Netflix 沿用原有网络门控，最长等待 120 秒；Bilibili / IPTV 沿用其直接启动流程。
- 目标应用本次新前台事件触发 180 毫秒淡出；淡出前立即返还输入，200 毫秒强制清理。派发后最迟 2 秒退场，不添加最短停留时间。
- **前台事件不等于视频首帧或已开始播放**。跨应用没有通用可靠的“内容已播放”信号；这个界面只覆盖轻幕的准备与启动交接。
- 首页、返回或明确切走取消当前请求。息屏暂停未完成的自动启动，唤醒可重试。服务关闭移除视图、计时器和动画。
- 实际发出 FlClash QuickAction 时，只给回到请求前应用 4 秒宽限；HOME 透明中继或唤醒恢复基线另有 1 秒宽限。同一条前台事件只处理一次。不会把任意应用当成目标就绪。
- 125 秒额外兜底覆盖包括前台基线查询在内的整个准备阶段；即使选择关闭外观仍生效。
- 网络失败移除全屏 Loading，保留可处理的错误卡。Netflix 原有失败卡的文本和可访问节点保留，以便可选守护接管。
- 可选守护的 Netflix 等待页使用同样视觉，失败停止动画并提供重试、取消。守护独立安装，目前不读取启动器的流光/静态选择，但遵循系统动画开关。

## 原生预览

`preview/DockPreviewActivity` 支持 `--es startup trace` / `still`，以及 `--es app netflix` / `bilibili`。它只演示界面，不启动视频、改网络或操作家居。模拟器图片必须标注为预览，不冒充电视截图。

## 真实电视截图

```sh
python3 scripts/capture-tv.py --serial TV_IP:5555 --output ./tv-current.png
```

脚本只调用指定设备的 `adb exec-out screencap -p`，不发送按键、不切换应用。目标小米电视会在 PNG 文件头前输出厂商诊断文字；移除前缀后可保存完整的原始截图。2026-10-30 实测取得 **1920×1080** 的电视屏保及轻幕日期/Clash 状态组件真实画面。

受保护的视频图层或 FLAG_SECURE 窗口仍可能留黑。普通界面可截图不意味着 Netflix 影片能截图，黑图也不是播放成功或失败的证据。本实现不修改视频应用、DRM 或系统安全设置。

参考：[Android 的 FLAG_SECURE 说明](https://developer.android.com/security/fraud-prevention/activities)。

## 2026-10-30 验证

- 原生 Android 14 模拟器：返回取消、HOME 取消、系统动画关闭、息屏清理、唤醒重试、基线事件重放不取消、目标启动后的焦点交接均通过。
- 纯 Java 策略测试 55 项通过，外观选择迁移测试通过，安装器 15 项测试通过。
- 目标电视：同签名覆盖升级 Home 8.6 / Overlay 8.34-dock / Guardian 2.11；家居、默认 HOME、无障碍服务及始终开启 VPN 配置保留。Netflix 数据目录 inode 未变。
- 已实测从轻幕发起 Netflix：网络检查后进入 Netflix 前台，等待页退出，既有 Google 服务弹窗守护继续工作。进入前台不等于确认视频已播放。
- 已实测从轻幕发起 YouTube：Clash 就绪后网络验证用时 1043 毫秒，随后派发应用；最终前台为 TizenTube，无 Loading、预览、错误卡或守护窗口残留。

本轮没有再次执行实机冷重启。此次结果包含默认 HOME、开机启动开关、后台服务与权限的持久配置核对，以及模拟器的启动生命周期测试，不能表述为新版实机冷启动验证。其他设备部署仍应完成一次真实冷启动与内容播放验收。

最终发布构建另在 Android 14 模拟器执行实际重启：自动进入有界网络等待，后续 HOME 可退出。此项是模拟器重启验证，仍不是该电视的实机冷启动验证。
