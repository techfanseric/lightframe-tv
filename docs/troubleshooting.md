# 排错与回退

| 现象 | 检查与处理 |
| --- | --- |
| ADB offline/拒绝连接 | 电视重新开启调试并确认授权；较新无线调试检查连接端口；不要操作同网段其他设备 |
| 重启后ADB消失 | 厂商固件行为。轻幕设置的ADB入口可直达开关页，不绕过系统开关 |
| install签名冲突 | 停止，不卸载、不清数据。确认是不是自签名.dock包，使用原密钥更新 |
| 首页未替换 | doctor检查当前HOME；安装与activate是两步；固件不支持命令时在系统设置手动选择 |
| 菜单不出现 | 检查悬浮窗、使用情况访问、电池后台权限；部分固件需遥控器再次授权 |
| 重复菜单/两套服务 | 激活时必须停用旧轻幕pair；不要停用原厂系统HOME。通过快照rollback恢复 |
| 流光停住不动 | 检查是否选择静态或系统关闭了动画；状态与网络检查仍可继续 |
| Loading 想退出 | 返回取消，首页选择其他应用；网络等待有上限，异常会退为可处理提示 |
| 截图无法读取或全黑 | 用 scripts/capture-tv.py 去除厂商 PNG 前缀；普通界面可截取，受保护画面仍可能留黑 |
| YouTube/Netflix一直等网络 | FlClash导入线路、VPN已授权、9090控制器开启、密钥非空且导入到.dock包；确认目标服务可达 |
| Google服务提示/Netflix不能播 | 参见兼容性，不默认禁用GMS；官方客户端/DRM/认证要独立检查 |
| 家居没设备 | TV能访问HA根URL；专用token有效；检查服务器账户权限；重新打开菜单等待目录刷新 |
| 日期和Clash同时消失 | 二者共用状态栏策略；智能模式在B站隐藏，设置成常开可检查 |
| 旧版家居分组不见了 | v0.2使用实体收藏，旧版分组在旧包保留；不会跨UID迁移加密token |

回退命令见[安装指南](install.md)。恢复记录默认在 `~/.lightframe/`；更换电视IP后使用 `--state /path/to/original-state.json`，向导会校验序列号与系统指纹；系统升级后指纹变化会拒绝自动恢复，应先检查并手动选择原HOME。记录丢失时先查当前HOME，不运行来自其他电视的恢复文件。

提交Issue时提供版本、型号、Android API、ABI、具体复现步骤和经过检查的错误片段。**不要上传完整logcat、家庭目录、订阅、令牌、签名私钥或个人状态文件。** 截图可能含账号、家居设备、代理节点；发送前自行检查。

## 停用与移除

先rollback或手动切回原桌面，再按需要在系统设置卸载新版。卸载轻幕会删除其配置与HA加密凭据；并不替代在HA撤销令牌。原厂桌面、视频账号和代理订阅无需清除。不要为了排错执行 `pm clear` 或批量卸载。
